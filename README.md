# MySQL Data Extractor

A simple desktop application built with Python that allows users to connect to a MySQL database, retrieve data, and export it to Excel.

This project was created as a practical demonstration of Python, SQL, database integration, data manipulation, and desktop application development.

## 🎯 Purpose

The main goal of this project is to demonstrate how Python can be integrated with a MySQL database to retrieve and process data and export it into Excel files.

This is a small portfolio project rather than a full-featured ETL system.

## 🛠️ Technologies

- Python
- MySQL
- MySQL Connector
- Pandas
- OpenPyXL
- CustomTkinter

## 🖥️ Features

- Connect to a MySQL database
- Execute SQL queries
- Retrieve database records
- Display extracted data
- Export data to Excel
- Simple graphical interface using CustomTkinter
